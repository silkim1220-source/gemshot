판매 사이트 미리보기

직접 파일로 올리고 싶다면 (선택)
  1. ‘판매 사이트 ZIP 받기’ → 압축을 풉니다.
  2. Netlify Drop에 풀린 폴더를 통째로 끌어다 놓으면 바로 주소가 생깁니다. (GitHub Pages도 가능)
  3. 손님은 구매하기 → 주문/결제 페이지(주문자·배송지 입력, 우편번호 검색, 개인정보 동의) → 주문 완료 화면에서 주문서를 보내고 계좌이체·토스·카카오페이·카드결제 링크로 결제합니다.
  4. ‘주문 자동 접수 주소’(Formspree 등)를 넣으면 주문이 자동으로 모입니다.
  5. 스마트스토어·쿠팡 링크를 상품에 넣으면 ‘바로 구매’ 버튼이 생깁니다.
※ 온라인 판매 시 사업자등록·통신판매업 신고 정보를 하단에 표시해야 합니다.
